# portfolio_reference

GitHub Pages로 만든 포트폴리오 스타일 예시 3가지입니다.

👉 **예시 보기: https://ejkim9090.github.io/portfolio_reference/**

| 스타일 | 특징 | 예시 |
|---|---|---|
| 1. 사이드바 원페이지형 | 왼쪽 고정 메뉴, 섹션 하나가 한 화면, 브라우저 틀 + 화면 탭 | [style1](https://ejkim9090.github.io/portfolio_reference/style1/) |
| 2. 발표형 슬라이드 | 큰 화면은 16:9 슬라이드(←/→ 키), 휴대폰은 스크롤 | [style2](https://ejkim9090.github.io/portfolio_reference/style2/) |
| 3. 카테고리 표지형 | 번호 사이드바, 분야별 큰 번호 표지, 경력 타임라인 | [style3](https://ejkim9090.github.io/portfolio_reference/style3/) |

## 내 포트폴리오로 바꾸는 법

1. 마음에 드는 스타일 폴더의 `index.html`을 복사합니다.
2. 이름·소개·프로젝트 글을 내 내용으로 바꿉니다.
3. `assets/mock/` 그림 자리에 내 화면 캡처(png·jpg·webp)를 넣습니다.
4. 내 GitHub 저장소에 올리고 **Settings → Pages**에서 배포합니다.

> 예시 속 인물(홍길동)과 숫자는 모두 가상입니다.
